# TripPlannrs Documentation

## Introduction

TripPlannrs is a web application designed to simplify the process of planning trips and creating detailed itineraries. It offers a range of features to help users organize their travel plans, from selecting destinations and accommodations to scheduling daily activities and managing budgets.

## Features

### Trip Planning

-   **Destination Selection:** Users can choose their desired destinations, and the application will provide relevant information and suggestions.
-   **Accommodation Options:** A variety of lodging options are available, allowing users to select the best fit for their budget and preferences.
-   **Activity Scheduling:** Users can plan daily activities, including sightseeing, dining, and entertainment, with the ability to customize their schedule.

### Itinerary Management

-   **Detailed Itineraries:** The application creates comprehensive itineraries, outlining each day's activities, locations, and timings.
-   **Customization:** Users can easily customize and adjust their itineraries based on their needs and preferences.
-   **Sharing:** Itineraries can be shared with fellow travelers or saved for future reference.

### Budget Management

-   **Expense Tracking:** Users can input and track their travel expenses, ensuring they stay within budget.
-   **Budgeting Tools:** The app offers tools to estimate and plan travel costs, helping users make informed decisions.

### User Accounts

-   **Personalized Experience:** Users can create accounts to save their trip plans and access them from any device.
-   **Data Security:** User data is securely stored and managed.
- **Social integration**: Users can share their plans with friends or post them for others to use.

### Additional Features

-   **Travel Tips:** Useful travel tips and recommendations are available to enhance the user experience.
-   **Contact Information:** Easy access to contact information for support or inquiries.
-   **Responsive Design:** The application is designed to work seamlessly across various devices, including desktops, tablets, and smartphones.

## Technologies Used

-   **Frontend:** Next.js, React, Tailwind CSS, Radix UI
-   **Backend:** Node.js
- **Database:** Supabase
-   **Authentication:** Firebase
-   **APIs:** Geoapify, Unsplash

## Getting Started

1.  **Installation:** Clone the repository and install the necessary dependencies.
2.  **Setup:** Configure the environment variables and database settings.
3.  **Running the App:** Start the development server.
4.  **Usage:** Navigate to the application in your browser and begin planning your trip.
